# Nostradamus Webapp — Complete Project Context

## Project doel

Voetbalpoule webapp voor Eredivisie voorspellingen.

Gebruikers:

* registreren account
* voorspellen uitslagen
* verdienen punten
* zien ranglijsten
* zien openbare voorspellingen na deadline
* weekloser kiest bonuswedstrijd

De app draait volledig online via:

* Vercel
* Supabase

# RLS policies predictions

Deze policies zijn nodig:

alter table predictions enable row level security;

drop policy if exists "Users can read own predictions" on predictions;
drop policy if exists "Users can insert own predictions" on predictions;
drop policy if exists "Users can update own predictions" on predictions;

create policy "Users can read own predictions"
on predictions
for select
to authenticated
using (auth.uid() = user_id);

create policy "Users can insert own predictions"
on predictions
for insert
to authenticated
with check (auth.uid() = user_id);

create policy "Users can update own predictions"
on predictions
for update
to authenticated
using (auth.uid() = user_id)
with check (auth.uid() = user_id);

# Puntensysteem

Exacte score goed:
12 punten

Winnaar goed + één teamscore goed:
4 punten

Winnaar goed:
3 punten

Winnaar fout + één teamscore goed:
1 punt

Bonuswedstrijd:
punten x2

# Belangrijke gameplay regels

## Bonus

Voor deadline:

* alleen weekloser ziet bonus

Na deadline:

* iedereen ziet bonus

Maximaal:

* 1 bonuswedstrijd

---

## Openbare voorspellingen

Voor deadline:

* verborgen

Na deadline:

* zichtbaar
